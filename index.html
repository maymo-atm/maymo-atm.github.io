Brown dwarf atmospheres

Brown dwarf polar vortex modeling

Multi-epoch atmospheric simulations for substellar objects — from surface flux maps to time-series predictions.

Get started → Try maymo-gui Read the paper

$ pip install maymo

What maymo does

🌀

Polar vortex geometry

Spherical cap flux maps with configurable vortex latitude, radius, and contrast.

📡

Time-series forward model

Multi-epoch photometric and spectroscopic predictions from rotating surface maps.

🪐

Brown dwarfs & companions

Applicable to isolated brown dwarfs and directly-imaged planetary companions.

maymo-gui

[ interactive preview ]

Run simplified vortex simulations in the browser — no Python required. Adjust vortex parameters and watch the lightcurve update in real time.
